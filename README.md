# Приблизительное вычисление площади пересечения 3 окружностей
ID посылки: 349333506 (с применением широкого прямоугольника)
## Сравнение результатов
По графикам видно, что используя более точную прямоугольную область оценка получается в среднем точнее. Это потому, что у нас область генерации точек меньше, и вероятность попадания в пересечение выше. При широком прямоугольнике подавлаяющее большинство точек летит мимо, из-за чего растет дисперсия. 
## Анализ точности
Можем заметить, что алгоритм дает очень хорошую приближенную оценку: сравнительная точность близка к 0.0001 при больших количествах точек. Приближенный прямоугольник даже при небольшом количестве точек дает приемлимый результат с ошибкой примерно в 1%.
